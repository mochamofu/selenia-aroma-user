# 再注文とお支払い

お客様がアプリの「再購入する」から、自分の香りを注文できる。注文は運営者アプリ（カルテ）の「注文」に入り、
施術者が 受付 → 作成中 → 発送済み と進める。

## 流れ

1. お客様：香りの詳細 →「再購入する」→ 容量・本数・お届け先・お支払い方法を選ぶ
2. はじめての方は、お届け先の扱いへの同意をいただく（同意の記録は `client_contacts.consent_*`）
3. 金額はサーバーで価格表から出し直す（画面から送られた金額は使わない）
4. お支払い
   - カード・PayPay など：Stripe のお支払いページへ移る。済むと Stripe から知らせ（Webhook）が来て「お支払い済み」になる
   - 銀行振込：振込先を案内する。施術者が入金を確かめて「支払いを確かめた」を押す
   - 次回ご来店時：店頭（Square など）で受け取ったら、施術者が「支払いを確かめた」を押す
5. 施術者：カルテアプリの「注文」で、配合（注文の容量に合わせた量）とお届け先を見て作り、発送する

価格表・送料・選べるお支払い方法は、運営者アプリの「設定」（管理者のみ）で入れる。価格表が空のうちは
再注文を受け付けない（以前の「外部ショップ」のリンクがあればそちらを出す）。

## Stripe をつなぐ

キーはリポジトリやチャットに書かず、Cloudflare に登録する。

1. Stripe に申し込む（事業者の名義・受け取り口座・カード明細に出る名前）
2. Stripe の管理画面 →「設定 → 決済手段」で、カード・PayPay・Apple Pay など出したいものを有効にする
   （どれを出すかはコードではなく、ここで決まる）
3. Stripe の管理画面 →「開発者 → Webhook」で送り先を足す
   - URL：`https://<お客様用アプリ>/api/payments/stripe/webhook`
   - イベント：`checkout.session.completed`、`checkout.session.async_payment_succeeded`
4. Cloudflare の Workers（selenia-aroma）→ 設定 → 変数とシークレット に、種類「シークレット」で登録する
   - `STRIPE_SECRET_KEY`（`sk_live_...`。試すときは `sk_test_...`）
   - `STRIPE_WEBHOOK_SECRET`（手順3で出る `whsec_...`）
5. 運営者アプリの「設定」で「カード・PayPay など（オンライン決済）」にチェックを入れる

キーが無いうちは、オンライン決済の選択肢は出ない（振込・来店時だけで動く）。

## 守っていること

- お客様が見られるのは、自分のお届け先と自分の注文だけ（誰の分かはログインで決め、画面から ID を受け取らない）
- カード番号はこのアプリを通らない（Stripe のページで入力する）
- Stripe からの知らせは署名を確かめ、注文に残した支払いページの ID と合うときだけ「お支払い済み」にする
- 施術者の控え（operator_note）はお客様に返さない
