# Selenia Aroma 現行デモアプリ仕様書

作成日: 2026年7月7日  
対象: 現在確認可能なデモアプリ  
想定用途: 先方確認・要件すり合わせ・本番開発前の画面仕様確認

## 1. 概要

本アプリは、アロマオイル購入者が自身の制作記録、ベースブレンド、追加オイル、使用メモ、再購入導線を確認できる会員向けアプリである。

当初は将来的なiOS/Androidアプリ化を見据えた構成としているが、現時点ではスマートフォン向けWebアプリ/PWAとして動作するデモ版である。

ブランド名は `Selenia Aroma` とする。

## 2. 現在の提供形態

現在はローカル環境で動作するデモアプリである。

- 起動URL: `http://localhost:3000/login`
- フレームワーク: Next.js
- UI: スマートフォン幅優先
- 認証: デモモードではローカル擬似ログイン
- データ: モックデータ中心
- 本番DB連携: Supabase接続を想定済み

## 3. 想定ユーザー

### 3.1 customer

購入者ユーザー。

主な操作:

- 自分のアロマ制作記録を見る
- ベースブレンドを確認する
- 追加されたアロマオイルと滴数を見る
- お気に入り登録する
- 再購入確認画面へ進む
- 気分・目的から一般精油を探す
- プロフィールを確認する

### 3.2 admin

管理者ユーザー。

主な操作:

- 顧客一覧を確認する
- アロマ制作記録を確認する
- アロマ制作記録を新規作成する
- ベースブレンド、追加オイル、ロット番号、脳波データ連携IDを入力する

## 4. 現在実装済み画面

### 4.4 アロマ詳細 `/aromas/[id]`

1つの制作記録の詳細画面。

表示内容:

- メイン画像プレースホルダー
- タイトル
- 制作日
- 気分・目的タグ
- テーマ

## 5. ベースブレンド仕様

ベースブレンドは12種類登録済み。

公開する情報:

- ブレンド番号
- 仮名
- 含まれる精油の種類
- 目的・効能カテゴリ

公開しない情報:

- 配合比率
- 内部レシピ

内部管理想定:

- 配合比率は `base_blend_private_recipes` でadminのみ扱う想定
- 顧客向けアプリには比率を出さない

## 6. 脳波データ連携

現時点では、外部カルテアプリまたは脳波データ管理アプリとの連携を想定し、アロマ制作記録に `brainwave_profile_id` を保持する。

現在の実装:

- 詳細画面に脳波データ連携IDを表示
- 管理フォームで入力可能

未実装:

- 実際の脳波グラフ表示
- 波形ファイル保存
- 外部カルテアプリとのAPI連携

- 決済機能は未実装
- iOS/Androidネイティブアプリではない
