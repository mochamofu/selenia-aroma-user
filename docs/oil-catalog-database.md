# Selenia Aroma アロマオイル説明DB

作成日: 2026年7月7日  
用途: 顧客向け精油図鑑、および事業者向けカルテアプリの基礎データ  
公開区分: 顧客向けに公開可能。ただし医療効果として断定しない。

## 取り扱い方針

このDBは、精油の香りの特徴、一般的な使われ方、相性のよい精油、注意メモを整理したものである。

表現上の注意:

- 医療効果を保証しない
- 治療効果として断定しない
- 妊娠中、乳幼児、持病、服薬中、敏感肌の場合は専門家確認を促す
- 光毒性や刺激性がある精油は注意を明記する

## DB項目案

| 項目 | 型 | 説明 |
|---|---|---|
| id | string | 内部ID |
| slug | string | URL用ID |
| name | string | 精油名 |
| botanical_name | string | 学名 |
| family | string | 科名 |
| scent_note | string | トップ / ミドル / ベース |
| scent_profile | string | 香りの印象 |
| overview | text | 概要 |
| common_uses | string[] | よく使われるシーン |
| mood_slugs | string[] | 対応する気分カテゴリ |
| blends_well_with | string[] | 相性のよい精油 |
| safety_note | text | 注意メモ |
| color | string | UI表示色 |

## 気分カテゴリ

| slug | 表示名 |
|---|---|
| relax | リラックスしたい |
| sleep | よく眠りたい |
| focus | 集中したい |
| energy | 元気になりたい |

## 精油一覧

### 1. ラベンダー

- slug: `lavender`
- 学名: `Lavandula angustifolia`
- 科名: シソ科
- ノート: ミドル
- 香りの印象: フローラル、ハーバル、やや甘い
- 概要: やわらかく親しみやすい香り。夜のリラックスタイムや落ち着きたい場面でよく選ばれる。
- よく使われるシーン:
