# 脳波アロマ管理アプリ 現行仕様・機能一覧

作成日: 2026年7月7日  
対象画面: `/operator`  
公開URL: `https://aroma-records-pwa.vercel.app/operator`  
対象アプリ: Selenia Aroma / 事業者向けWeb管理画面  
文書目的: 現時点のアプリ機能、画面構成、保持データ、未実装範囲を整理する。

## 1. アプリ概要

本アプリは、脳波アロマ測定サービスの事業者が、利用者ごとのカルテ、1分測定の脳波画像、香り制作履歴、配合レシピ、事前ヒアリング回答、禁忌・注意事項、ベースブレンド情報、追加精油情報を一元管理するためのWeb管理画面である。

現行版は正式運用前のデモ実装であり、UI、業務フロー、データ項目、履歴連動の確認を目的としている。医療診断を行う画面ではなく、画面内の「診断」は香り提案・測定結果整理の業務表現として扱う。

## 2. 現行提供形態

- フレームワーク: Next.js 16.2.6
- React: 19.2.4
- UI: Tailwind CSS 4系
- アイコン: lucide-react
- 実装ファイル: `src/app/operator/page.tsx`
- データ保持: フロントエンド内のモックデータとブラウザ内state
- 公開方式: Vercel Production URL
- 認証: 未実装

現行URLはURLを知っている人が閲覧できる状態である。実在顧客情報や実測画像は入れない前提で扱う。

## 3. 主要画面

### 3.1 顧客カルテ

日常運用の中心画面。PC幅では3カラム構成、タブレット・スマートフォン幅では縦積み表示になる。

主な表示:

- 顧客階層
- 顧客カルテ追加ボタン
- 選択中のカルテ概要
- 脳波画像一覧
- 画像アップロード欄
- 過去の診断・制作履歴
- 選択中の制作履歴詳細
- ヒアリングシート回答履歴
- 画像プレビュー
- 香り制作記録

### 3.2 ベースブレンド図鑑

12種類のベースブレンドを一覧表示する。通常表示では、店舗オペレーター向けにベースブレンドの内部情報を表示しない。

通常表示:

- ベースブレンド番号
- ブレンド名
- 説明
- 目的カテゴリ
- ベース追加ボタン

管理者解除後のみ表示:

- 構成精油
- 内部比率
- 事業者用メモ

現行デモでは、ベースブレンド図鑑右上の小さなロックアイコンから管理者パスワードを入力すると内部情報を一時表示する。デモ用パスワードは `selenia`。これは画面確認用の簡易制御であり、本番セキュリティではない。

### 3.3 追加オイル・精油図鑑

36種類の追加精油を一覧表示する。

表示内容:

- 精油名
- 学名
- 科名
- ノート分類
- 香りの印象
- よく使う場面
- 相性の良い精油
- 注意メモ

操作:

- 精油名・学名・香り説明によるテキスト検索
- 気分カテゴリによる絞り込み
- 精油追加

アップロード仕様:

- ふりがな
- 誕生日
- 誕生日から自動計算した年齢

年齢は誕生日と回答日から自動計算する。

禁忌・注意フラグ:

- 妊娠中

これらは医療判断ではなく、調香前の確認メモとして扱う。

### 4.5 香り制作記録

右カラムに選択中の制作記録を表示・編集する。

入力・表示項目:

- 制作名
- 制作日
- ベースブレンド
- 完成量 mL
- 配合材料
- 配合量 μL
- 作成者メモ

配合管理:

- 滴数ではなく、μL / mLで管理
- 表示単位はμLとmLで切り替え可能
- 5mL / 10mLボタンで完成量を切り替え可能
- 元履歴の比率を維持して各材料量を換算

計算式:

```text
換算係数 = 指定完成量mL / 履歴の元完成量mL
換算後の各材料量μL = 履歴の各材料量μL × 換算係数
```

重要仕様:

- 「滴」は使用しない
- 「基準容量」という別概念は使わない
- 4850μLから5000μLへ補正するような再計算は行わない
- 履歴データ自体が5mLまたは10mLに一致する設計

### 4.6 一時保存

## 7. 将来拡張時の接続ポイント

現行アプリは、将来的に実測データを受け取る場合、以下の単位へデータを紐づける構造が適している。

### 7.1 顧客への紐づけ

受信データは、顧客IDまたは顧客を一意に判定できるキーへ紐づける必要がある。

推奨される最低項目:

```text

```

### 7.2 脳波画像への紐づけ

現行UIでは、脳波データの主表示は画像である。受信後は、以下のいずれかを `brainwave_images` 相当のデータとして登録する想定。

```text

```

### 7.3 制作履歴への紐づけ

香り制作履歴は、選択した脳波画像と同じ履歴に紐づく。将来の永続化では、制作履歴側に以下の参照を持たせる想定。


## 9. セキュリティ・権限方針

現行デモは認証なしで閲覧できるため、実在顧客情報、実測画像、内部配合情報を入れない。

本番化時に必要な権限制御:

- ログイン認証
- 店舗オペレーター権限
- 管理者権限
- ベースブレンド内部情報の管理者限定表示
- 顧客データの閲覧範囲制御
- 画像・制作履歴の編集権限制御
- 監査ログ

現行の `selenia` パスワードはデモ用の簡易表示切替であり、本番認証としては扱わない。

## 10. 現行版の確認済み事項

確認済み:

- `/operator` が公開URLで表示できる
- 顧客を切り替えると履歴、画像、制作記録が切り替わる
- 過去の診断・制作履歴を選択すると、該当履歴の脳波画像、香り制作記録、ヒアリング回答が切り替わる
- ヒアリングシート回答履歴は中央カラムの制作履歴詳細下に表示される
- 画像プレビューと香り制作記録は右カラムに表示される
- 画像アップロード上限は10MB
- 配合量はμL / mLで表示できる
- 5mL / 10mL換算ができる
- ベースブレンド内部情報は通常表示では出ない
- 管理者解除後のみ内部比率と構成精油を表示する
- 精油図鑑の検索・絞り込みができる
