# D1のコンソールに貼るSQL（予備の手段）

**通常は `npm run db:migrate` を使うこと。** こちらは分割もコピペも不要。
このフォルダは、wranglerが使えない環境から手作業で流すときの予備。


Cloudflareダッシュボードの D1 → Console は**入力欄が1行しかない**。
複数行のSQLを貼ると改行が失われ、先頭の `--` コメントが以降すべてを
コメント扱いにするため、1文も実行されない。

そのため、このフォルダのファイルは次の形にしてある。

- `--` と `/* */` のコメントを完全に除去（文字列リテラル内は保護）
- 改行を除去して1行にまとめる
- `PRAGMA` を除去（D1が受け付けない。外部キーはD1側で既定で有効）
- 1ファイル6000文字以内に分割

## 実行する順番

1. `schema-01of02.sql`
2. `schema-02of02.sql`
3. `seed-01of05.sql`
4. `seed-02of05.sql`
5. `seed-03of05.sql`
6. `seed-04of05.sql`
7. `seed-05of05.sql`

各ファイルの中身を全部コピーして入力欄に貼り、Execute を押す。
7回繰り返す。終わると15テーブル、顧客8名・ベースブレンド12種・精油36種が入る。

`/tables` と入力するとテーブルの一覧が出るので、途中経過を確認できる。

## 作り直すとき

`cloudflare/d1/*.sql` を編集したあとに、リポジトリのルートで実行する。

    node scripts/build-d1-console-sql.mjs

元になるのは 0001 / 0003 / 0004（スキーマ）と 0002（初期データ）。
